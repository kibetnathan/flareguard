Flareguard Test Page

Manual test harness for detector results, popup warning routing, logs, and trust settings. Open this page in a tab, keep it active, then open the Flareguard popup.

Open via chrome-extension://<EXTENSION_ID>/test-page.html. Content scripts do not auto-run on chrome-extension:// pages, so this page emits scan/log messages directly for popup/background testing. For the real in-page 3/3 block overlay, test on a normal https:// page where content scripts run.

1) Clean (1/3)

Emits a clean scan result for this tab.

2) Possible (2/3)

Emits a medium-risk result; popup should show flagged status (not redirect to warning page).

3) Likely (3/3)

Emits a high-risk result; popup should redirect to the warning page. Real page-block overlay requires a normal web page with content scripts.

Manual controls

Dynamic fixture area

No fixtures injected.

Checklist

- Test/Script logs page receives background + test-page logs.
- Popup shows 1/3 and 2/3 results normally.
- Popup redirects to warning page for 3/3.
- Warning page can save correct URL and navigate (valid https URL).
- Settings can trust/remove hostname.
- On a real https page scoring 3/3, content script blocks interaction until hostname trusted and page refreshed.
